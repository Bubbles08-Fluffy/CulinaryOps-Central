# CulinaryOps Central

## Overview

CulinaryOps Central is a desktop application developed to help dining services managers organize and manage daily operations from one centralized system. The application replaces manual spreadsheets and paper records with a user-friendly interface backed by a SQLite database.

This project was developed as my Senior Seminar capstone project for Auburn University at Montgomery.

---

## Features

- Dashboard with operational metrics
- Vendor management
- Employee management
- Invoice management
- Meal count tracking
- Sales record management
- Create, Read, Update, and Delete (CRUD) functionality
- SQLite database integration
- Modern desktop interface using CustomTkinter

## Installation

### Clone the repository

```bash
git clone https://github.com/Bubbles08-Fluffy/CulinaryOps-Central.git
```

### Navigate into the project

```bash
cd CulinaryOps-Central
```

### Install dependencies

```bash
pip install customtkinter
```

### Run the application

```bash
python main.py
```
